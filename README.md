# Wattalyze – Electricity Bill Calculator

Wattalyze is an Android application developed for the ICT602 Individual Assignment.

## Features
- Calculate monthly electricity charges.
- Apply electricity rebates from 0% to 5%.
- Save bill records using a local database.
- View, edit and delete bill history.
- View student and application information.

## Technology
- Android Studio
- Java
- XML
- SQLite Database
